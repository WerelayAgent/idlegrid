# IdleGrid ($IDLEGRID)

> **Your idle GPU, earning.**
> IdleGrid is a decentralized physical infrastructure network (DePIN) for GPU compute. Link your idle GPU to run verified AI workloads (LLMs, image gen, Whisper, agentic tools) and earn $IDLEGRID plus tokenized NVDA yields.
